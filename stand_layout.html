1 АКТУАЛЬНОСТЬ
В эпоху развития ИИ и цифровизации алгоритмическая грамотность — базовый навык XXI века. Традиционное школьное обучение информатике сталкивается с системными барьерами: нехваткой интерактивной практики, сложностью локальной настройки сред CPython и рутинной проверкой. Существующие зарубежные сервисы (LeetCode, Codeforces) сложны для школ и требуют платных подписок. Необходима отечественная школьная платформа с мгновенным откликом и умным наставником.
2 ЦЕЛЬ ИССЛЕДОВАНИЯ
Проектирование, алгоритмическая реализация и педагогическое обоснование интерактивной образовательной веб-платформы Smart Code для массового обучения школьников алгоритмизации, соревновательному кодингу и спортивному программированию.
3 ЗАДАЧИ ИССЛЕДОВАНИЯ
  • Анализ систем автоматизированного тестирования кода и выявление пробелов для школьного образования.
  • Разработка легковесной безопасной AST-песочницы Python без задержек контейнеризации (<15 мс).
  • Интеграция Сократического Gemini AI-ментора с запретом на выдачу готового кода и каскадом Fallback Chain.
  • Создание соревновательного модуля Code Battle 1v1 с транзакционной защитой от Race Condition.
  • Реализация модуля виртуальных классов для учителей и античит-контроля сдачи решений.
  • Педагогическая апробация на 150 учащихся и стресс-тестирование стека (44/44 автотестов).
4 МЕТОДЫ ИССЛЕДОВАНИЯ
Статический синтаксический анализ AST-деревьев Python; транзакционное управление параллелизмом СУБД (select_for_update); педагогический эксперимент (КГ/ЭГ, 100 уч.); онлайн-анкетирование 150 респондентов; методы математической статистики.

Исследовательский вопрос и рабочая гипотеза
Вопрос: Как ликвидировать технический барьер и стимулировать познавательную мотивацию школьников при изучении сложных алгоритмов без риска бездумного списывания?
Гипотеза: Интеграция изолированной AST-песочницы, диалогового Сократического AI-ментора и соревновательных PvP-дуэлей 1v1 повысит успеваемость более чем на 20% и сформирует культуру академической честности.
АРХИТЕКТУРА И ТЕХНОЛОГИЧЕСКИЕ ИННОВАЦИИ СИСТЕМЫ Service-Layer Architecture (Django 5.2 / Python 3.11)
1. Легковесная AST-песочница
SecurityASTValidator обходит синтаксическое дерево, блокируя import, eval, exec и интроспекцию. Время отклика — 12 мс (в 60 раз быстрее Docker).
2. Socratic AI-ментор (Gemini)
Строгий системный запрет на выдачу готового кода. Ментор задает наводящие вопросы по логике ошибки. Каскадный Fallback Chain при сбоях сети.
3. PvP Code Battle 1 на 1
Синхронные турнирные дуэли в реальном времени. Транзакционный лок select_for_update() полностью исключает Race Condition.
4. Античит-контур (TaskSolutionView)
При открытии эталонного разбора система навсегда отключает выдачу опыта (XP), сохраняя честность рейтинга и мотивацию.
